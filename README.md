Movie website that allows you to search a movie, or upcoming movie see popular movies and actors, watch the trailers and create a fantasy movie.

![alt text](<Screenshot 2026-08-28 at 11.08.57.png>)

It is built with React, Typescript, The MovieDatabase API.

Features

- Movie Features
- View upcoming movies
![alt text](<Screenshot 2026-08-28 at 11.19.08.png>)

- View detailed movie information
- View movie posters and images
- View movie reviews
- View movie cast information
- Watch movie trailers
![alt text](<Screenshot 2026-08-28 at 11.21.41.png>)

- Add movies to favourites
- Remove movies from favourites
![alt text](<Screenshot 2026-08-28 at 11.23.20.png>)
- Search movies by title
- Filter search results by genre
- Filter search results by minimum rating
![alt text](<Screenshot 2026-08-28 at 11.24.13.png>)
- Pagination support for search results

Actor Features

- Browse popular actors
- View actor biography and details
- View actor movie credits
- Add actors to favourites
- Remove actors from favourites
- View favourite actors page
![alt text](<Screenshot 2026-08-28 at 11.28.55.png>)

Fantasy Movie Feature

Users can create their own fantasy movie containing:

- Title
- Overview
- Genre
- Release Date
- Runtime
- Production Company

Created fantasy movies are stored in application state and displayed on a dedicated page.
![alt text](<Screenshot 2026-08-28 at 11.30.49.png>)

![alt text](<Screenshot 2026-08-28 at 11.31.07.png>)
